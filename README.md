# SimplePython (`import SimplePython`)

Write Python with **zero indentation**, curly braces `{ }`, and beginner-friendly commands (`say`, `ask`, `repeat`, `luck`, `otherwise`).

## Quick Start
1. Put `SimplePython.py` in your project folder.
2. Create `main.sp` with curly-brace code:
```text
action greet() {
say("Hello from SimplePython!")
}
greet()
```
3. Run it from `main.py`:
```python
import SimplePython
SimplePython.run_file("main.sp")
```
